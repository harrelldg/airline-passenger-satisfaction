# Dataset

Download the public **Airline Reviews** dataset:

https://www.kaggle.com/datasets/juhibhojani/airline-reviews

Save the main CSV as `data/airline_reviews.csv`, or pass another path with `--data`.

The original group analysis used approximately 23,000 reviews with these key fields:

- Targets: `Recommended`, `Overall_Rating`.
- Text: `Review_Title`, `Review`.
- Ratings: `Seat Comfort`, `Cabin Staff Service`, `Food & Beverages`, `Ground Service`, `Inflight Entertainment`, `Wifi & Connectivity`, `Value For Money`.
- Categories: `Type Of Traveller`, `Seat Type`, `Verified`.

Review the Kaggle licence and attribution terms before downloading or redistributing the data.
